🍎 我用 Mac

開始前，先確認三件事

  • 是一台 Windows 10 或 Windows 11 的電腦
  • 硬碟還有 2GB 以上 的空間
  • 接下來 10～20 分鐘網路不要斷（它要自己下載一些東西）
💡 不用先裝 Python、不用管理員權限、不會動到你電腦原本的任何設定。所有東西都裝在同一個資料夾裡，以後不想要了，整個資料夾丟垃圾桶就乾淨了。

安裝四步驟

只有第一次要做，之後都只要點 start.bat

1

下載工具包

⬇️ 下載工具包 downloader-kit.zip・約 20KB・秒下載

檔案會進到你電腦的「下載」資料夾。

2

解壓縮到桌面（最多人卡在這一步）

⚠️ 不可以直接在壓縮檔裡面點開來用
很多人下載完直接雙擊 zip、看到裡面的檔案就點下去——這樣一定裝不起來，因為那只是 Windows 的「預覽」，檔案其實還在壓縮檔裡。

正確做法：

  1. 找到剛下載的 downloader-kit.zip
  2. 對它按滑鼠右鍵 → 選「全部解壓縮」
  3. 位置選桌面（或任何你找得到的地方，但不要放在 USB 或網路磁碟）
  4. 按「解壓縮」→ 會跳出一個新資料夾，裡面躺著十幾個檔案
✅ 判斷成功沒：新資料夾的視窗標題列，路徑要長得像 C:\Users\你的名字\Desktop\downloader-kit。如果路徑裡面有 Temp，就是還沒真的解壓縮，回去重做一次。
（不過就算你做錯了也不會怎樣——程式會擋下來，直接跳視窗教你重做。）
3

點兩下 setup.bat，然後去泡杯咖啡

它會自動把需要的東西全部裝好，你完全不用選、不用按。中間會跳出一個黑色視窗一直捲字，那是正常的，不要關掉它。

🔵 跳出藍色的「Windows 已保護您的電腦」？
按左邊小小的「其他資訊」→ 再按右下角「仍要執行」。
這是 Windows 對「從網路下載的檔案」的例行提醒，不是說你中毒。
⏳ 要跑多久？
大約 5～15 分鐘，看你的網速（它總共要抓約 800MB 的元件）。
黑視窗上會顯示下載進度、速度、還要幾分鐘，數字有在跳就是正常的。
跑完會跳出一個「安裝完成」的對話框——看到它才算裝好。
🔁 中間網路斷掉、或不小心關掉視窗？
沒關係，再點一次 setup.bat 就好。它會跳過已經裝好的部分，從斷掉的地方接著裝。
4

點兩下 start.bat，開始用！

瀏覽器會自動跳出「影片下載器」網頁。把影片網址貼進框框（一行一條，或整坨貼上都行）→ 按「下載」→ 它會自己排隊跑完。

  • 「下載完自動產逐字稿」預設有勾，不需要的話再取消
  • 影片存到桌面「影片下載」資料夾，逐字稿是旁邊的 檔名_逐字稿.txt
  • 想換存檔位置：網頁下面「存檔位置」那行按「換資料夾」，可以挑任何資料夾、也可以當場開一個新的；選過會記住
  • 用完直接把黑色視窗關掉就好
🌐 黑視窗有在跑，但沒看到網頁？
自己打開常用的瀏覽器，在網址列輸入：http://127.0.0.1:8765

平常還能這樣用

  • 手上已經有影片／錄音檔要打逐字稿？
    把檔案（或整個資料夾）用滑鼠拖到 transcribe.bat 上面放開，就開始轉。
    mp3、m4a 錄音檔也吃。會議錄音、上課錄音都可以。
  • 抓下來的影片格式怪怪的、剪輯軟體讀不到？
    拖到 convert-h264.bat 上面放開，轉成通用格式。

卡住了？先做這一件事

點兩下資料夾裡的 check.bat。

它會自動幫你體檢，在同一個資料夾產生一個 診斷報告.txt，並且直接打開給你看。
把那個檔案傳給介紹你來的朋友就好——上面寫得清清楚楚卡在哪一關，你不用會形容、也不用截圖。

如果是安裝那一步失敗，資料夾裡還會有一個 setup-log.txt，一併傳過去更快。

安裝兩步驟

Mac 只要複製貼上一行字，比 Windows 還快

1

打開「終端機」

  1. 按鍵盤 command ⌘ + 空白鍵（螢幕中間會跳出搜尋框）
  2. 打 終端機（或打 terminal）
  3. 按 Enter，會跳出一個白白／黑黑的視窗，上面有一些英文字
✅ 這個視窗就是「終端機」，長得很工程師沒關係，你只會用到它一次。
2

貼上這一行，按 Enter，然後去泡杯咖啡

curl -fsSL https://catpawwedding.github.io/lazypack/downloader-kit/mac/install.sh | bash

回到終端機視窗，按 command ⌘ + V 貼上，再按 Enter。接著它就會自己跑，你完全不用選、不用按。

⌨️ 貼上之後如果它問你密碼？
不會問。這個工具不需要你的電腦密碼。如果真的跳出要密碼，代表你貼錯東西了，關掉重來。
⏳ 要跑多久？
大約 5～15 分鐘（總共要抓約 800MB 的元件）。畫面上會有進度條和百分比一直在跑，有在動就是正常的。
跑完會跳出一個「安裝完成」的對話框，桌面也會多出兩個圖示——看到才算裝好。
🔁 中間網路斷掉、或不小心關掉視窗？
沒關係，把同一行再貼一次就好。它會跳過已經裝好的部分，從斷掉的地方接著裝。
✅ 裝好後桌面會多出「影片下載器」和「轉逐字稿」兩個檔案，以後點兩下就能用，不用再開終端機。

裝好之後怎麼用

  • 下載影片
    點兩下桌面的 影片下載器 → 瀏覽器跳出下載器網頁 → 貼網址 → 按下載。
    影片存到桌面「影片下載」資料夾，逐字稿是旁邊的 檔名_逐字稿.txt；想換地方就按網頁上的「換資料夾」，選過會記住
  • 已經有影片／錄音檔要打逐字稿
    點兩下桌面的 轉逐字稿 → 跳出選檔案的視窗 → 選檔案（按住 command ⌘ 可以一次選很多個）→ 開始轉。
    mp3、m4a 錄音檔也吃。會議錄音、上課錄音都可以。
🍎 第一次點兩下，Mac 跳出「無法打開，因為來自未識別的開發者」？
正常情況不會跳（這兩個檔是在你自己電腦上產生的，不算下載檔）。萬一真的跳了：對那個圖示按住 control 再點一下 → 選「打開」→ 再按一次「打開」，之後就不會再問了。

常見問題

它會不會偷裝東西、有沒有病毒？

不會。它只做三件事：下載一份官方的 Python（來自 python.org 的官方建置）、下載開源的影音工具 ffmpeg、下載開源的語音辨識模型。全部裝在同一個資料夾裡（Windows 是你解壓縮出來的那個，Mac 是「個人 → 影片下載器」），不寫系統設定、不設開機啟動、不需要管理員權限或密碼。不想要了整個資料夾刪掉就乾淨。

🍎 Mac：叫我把一行字貼到終端機，這樣安全嗎？

合理的警覺。那一行做的事是「去這個網址把安裝腳本抓下來執行」，網址就是你現在看的這一頁的同一個站（catpawwedding.github.io）。腳本內容是公開的，可以先看過再決定：點這裡看原始碼。
它不會要你的密碼（沒有 sudo）、只寫入「個人 → 影片下載器」跟桌面那兩個捷徑。

安裝跑到一半停住不動了？

總共要抓約 800MB，網路慢的時候會久一點。但畫面上應該一直有數字或進度條在動——有在動就是正常的，先等 10 分鐘。真的整個不動了，就關掉視窗重來（Windows 重點 setup.bat／Mac 把那行指令再貼一次），它會從斷掉的地方接著裝。

🪟 Windows：跳出 Microsoft Store 叫我裝 Python？

把 Store 視窗關掉就好，不要在那邊裝。這一版工具包自己帶 Python，不需要你電腦上有 Python。（如果你看到這個畫面，代表你點到的是舊版工具包，請回到本頁重新下載。）

我電腦本來就有 Python / Anaconda，會不會打架？

不會。這一版刻意不碰你系統上的 Python，它用的是自己資料夾裡那一份，兩邊完全隔開。

🍎 Mac：我有開 iCloud 桌面同步，影片會被上傳嗎？

預設會。影片預設存在桌面的「影片下載」資料夾，如果你開了 iCloud 的「桌面與文件」同步，那些影片會被傳上 iCloud 吃你的空間。介意的話最簡單：打開下載器網頁，按「換資料夾」把存檔位置改到「個人 → 影片」底下，之後就都存在那裡，不用再自己搬。

某支影片顯示「失敗」？

只能下載公開影片。私人帳號、限好友、需要登入才看得到的影片抓不到，這是正常的，不是壞掉。

逐字稿沒有標點符號、也不分段？

這是語音辨識的先天限制。把 txt 內容丟給 ChatGPT 或 Claude，說「幫我加標點、分段落」，三秒就整理好了。長錄音的最後面如果出現同一句話一直重複，那是 AI 在沒人講話的地方「幻聽」，刪掉即可。

第一次轉逐字稿特別久？

如果安裝時語音模型沒抓成功，第一次轉稿會先補抓約 500MB 的模型，只有那一次會慢，之後就很快（10MB 的短影音大約 11 秒）。

🪟 Windows：可以放在 USB 隨身碟或公司網路磁碟嗎？

不建議，會裝失敗。請放在電腦本機，最簡單就是桌面。

可以兩台電腦都裝嗎？一台 Windows 一台 Mac？

可以，兩邊各自照各自的分頁裝一次就好，互不影響。

下載的影片請僅供個人分析、學習使用。尊重原創作者，不要把別人的內容盜搬重新上傳。
