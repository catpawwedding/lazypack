裝好之後長怎樣？

點兩下捷徑 → 自動打開一個「下載器網頁」→ 把影片網址貼進去（一次貼一堆也行）→ 按下載。影片自動存到桌面「影片下載」資料夾，旁邊還躺著一份打好的繁體逐字稿。做自媒體拆片、蒐集素材、留存靈感都好用。

安裝三步驟（只有第一次要做）

1

下載工具包，解壓縮到桌面

⬇️ 下載工具包（zip，約 15KB）
需要 Windows 10 或 11 的電腦，手機不能用

下載後對 zip 檔按右鍵 →「全部解壓縮」，解到桌面。會得到一個裝著十來個檔案的資料夾。

2

點兩下 setup.bat（自動安裝，跑一次就好）

它會自動裝好需要的三樣東西：Python、下載＋轉錄引擎、ffmpeg。全程自動，等它跑完即可（幾分鐘，看網速）。

🔵 跳出藍色「Windows 已保護你的電腦」？
按「其他資訊」→「仍要執行」。這是 Windows 對網路下載檔案的例行警告，不是中毒。
🔁 它說「裝好 Python 了，請關掉視窗再跑一次」？
照做：關掉黑視窗，再點兩下 setup.bat 一次，讓它把剩下的裝完。
3

點兩下 start.bat，開始用！

瀏覽器會自動跳出綠色的「影片下載器」網頁。把影片網址貼進框框（一行一條或整坨貼都行）→ 按「下載」→ 去忙你的，它會自己排隊跑完。

  • 「下載完自動產逐字稿」預設有勾，不想要再取消
  • 影片存到桌面「影片下載」資料夾，逐字稿是旁邊的 檔名_逐字稿.txt
  • 第一次跑逐字稿會先下載 500MB 的語音模型，那一次比較慢，之後就快了
🌐 黑視窗有在跑，但沒看到網頁？
它可能開在你沒在用的瀏覽器（例如 Edge）。自己打開常用的瀏覽器，網址列輸入：http://127.0.0.1:8765

平常還能這樣用

  • 手上已經有影片／錄音檔？直接把檔案（或整個資料夾）拖到 transcribe.bat 上放開，就轉出逐字稿。錄音檔 mp3 / m4a 也吃。
  • 抓下來的影片只有聲音沒畫面？拖到 convert-h264.bat 轉成正常格式。

常見問題

跳出 Microsoft Store 要我裝 Python？

把 Store 關掉，去點兩下 setup.bat。那是 Windows 內建的「假 python 捷徑」，setup.bat 會幫你裝真的。

某支影片顯示「失敗」？

只能下載「公開」影片。私人帳號、限好友、要登入才看得到的影片抓不到，這是正常的。

逐字稿沒有標點、不分段？

這是語音辨識的先天限制。把 txt 丟給 ChatGPT 或 Claude 說「幫我加標點分段」就整理好了。

都試了還是不行？

點兩下資料夾裡的 check.bat，把跳出來的整個視窗截圖，傳給介紹你來的朋友（或丟給 AI），一看就知道卡在哪。

⚠️ 使用約定

下載的影片僅供個人分析、學習使用，請尊重原創作者，不要盜搬他人內容重新上傳。
