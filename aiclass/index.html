04

      

        
實戰：拆你的第一支稿

        
🎯 做完這步：拿到一支「你本人可以直接開拍」的口播稿，而且存進了資料庫。

      

    

    

      

        
找一支同行的爆款影片（讚數、留言明顯高的那種），用第 1 堂的逐字稿工具：丟連結 → 自動下載 → 拿到逐字稿文字檔。

        
在 Claude Code 貼上逐字稿＋打「拆稿」，送出。

        
檢查輸出是不是七段都有：爆款核心 → 七宗罪情緒邏輯 → 八大模組選擇 → 九大流量法則 → 60-70 秒主攻口播稿 → 為什麼這版更容易爆 → 純口播稿。缺一段就跟它說「照七段格式補完整」。

        
看最後的「純口播稿」——這段是你要複製去提詞機的，裡面不准有任何 # 標題、HTML 標籤、字卡標記。有混進去就叫它重出。

        
最後說一句：「幫我存進 Notion 的文案資料庫」→ 去 Notion 確認多了一列、狀態是「文案完成」。

      


      
實際對話長這樣：

      

        
你拆稿

Claude## 爆款核心
- 核心矛盾：大家以為○○，其實○○……
（七段完整輸出）

## 純口播稿
你知道嗎，中壢每三間成交的房子……

        
你幫我存進 Notion 的文案資料庫

        
Claude✅ 已新增到「文案資料庫」：標題＝鉤子句、狀態＝文案完成。

      


      
拆出來不像你說話？ 回 STEP 01 把「語氣」寫得更具體（最好補一句你平常真的會講的話當範例），存檔後重跑 STEP 02 的「寫入我的設定」指令，再拆一次。這是最值得花時間調的一個欄位。

      
進階玩法：把「你自己以前發過、成效普通」的舊文案丟進去拆——它會指出弱點在哪、怎麼改會更爆。這招課後回家一定要試。


      
    

  


  
  

    

      
05

      

        
實戰：生你的第一份懶人包

        
🎯 做完這步：拿到一份掛著你品牌、手機打開很好看的 HTML 懶人包。

      

    

    

      
先懂邏輯：影片結尾埋一句「留言『關鍵字』我傳給你一份『○○懶人包』」→ 粉絲留言 → 你私訊發懶人包 → 順勢加 LINE。懶人包就是把留言變名單的鉤子。


      
前提檢查：你的影片文案結尾要有明確的 CTA，例如——「如果你也擔心踩雷，我整理了一份『借戶籍避雷清單』，留言『戶籍』我傳給你。」關鍵字和懶人包名稱缺一不可；沒有的話先把文案結尾補上這句再來。


      

        
在 Claude Code 貼上影片文案＋打「生懶人包」，送出。

        
Claude 會先停下來跟你確認方向（這是故意的，不是壞掉）：它會說出抓到的主題／關鍵字／名稱，以及「留言的粉絲是誰、他真正想拿到什麼、看完要從 A 變 B」，還有打算鋪哪幾個章節。

        
看一個重點就好：章節是不是「影片重播」？粉絲要的是影片承諾但沒講完的工具。方向對就回「OK」；不對就說「粉絲要的是○○，重排章節」。

        
拿到 HTML 檔案（Claude Code 會存在你的資料夾，路徑會告訴你）。

        
用手機打開驗收，照下面清單檢查。

06

      

        
把懶人包交到粉絲手上（三條路）

        
🎯 做完這步：粉絲留言後，你 10 秒內有東西可以私訊給他。

      

    

    

      

        

          
① 直接傳檔案零難度

          
把 HTML 檔案用 LINE 直接傳給粉絲，手機點開就能看。今天就能用，先跑起來最重要。

        

        

          
② Netlify Drop低難度

          
打開 app.netlify.com/drop（免費），把 HTML 檔用滑鼠拖進去，10 秒拿到一條公開網址，私訊貼連結就好。粉絲點連結比開檔案更順。

        

        

          
③ GitHub Pages中難度

          
有 GitHub 帳號的人：開一個 repo → Settings → Pages 開啟。網址永久、所有懶人包累積在同一個倉庫，越做越多變成你的內容資產。課後想升級再走這條（也可以直接叫 Claude Code 幫你設定）。

        

      

      
私訊話術範例：「嗨，謝謝你看完影片！這份『○○懶人包』給你：（連結）。看完有任何問題都可以直接問我 😊」——固定開頭＋連結＋一句歡迎提問，不用寫長。


      
    

  


  
  

    

      
07

      

        
把閉環跑起來（回家後的功課）

        
🎯 這套系統的複利，從你「回填第一筆流量數字」那天開始。

      

    

    

      

        
每週拆 2-3 支同行爆款 → 口播稿存進文案資料庫（狀態＝文案完成）。

        
挑一支拍片發佈 → 影片 CTA 埋「留言『關鍵字』領『○○懶人包』」→ Notion 該列改「已發佈」、填發佈日。

        
發佈當天生好懶人包 → 粉絲留言就私訊發 → 順勢加 LINE。

        
發佈滿一週，回 Notion 填流量數／讚／留言／分享——這步最多人偷懶，也最值錢。

        
月底按「流量數」排序看一次：哪種鉤子、哪種主題是你的菜，下個月加倍做。

      


      
    

  


  
  

    

      
FAQ

      
卡住了看這裡

    

    

      
Claude 說找不到我的文案資料庫？
先確認 STEP 03 的 claude mcp add 有跑過、授權有點同意（可以問 Claude「你接得到我的 Notion 嗎」）。再確認資料庫名稱就叫「文案資料庫」這五個字，多一個字少一個字它都可能找錯。

      
問「你有哪些 skill」沒看到 viral-breakdown？
檢查兩件事：① skill 資料夾是不是放在 .claude\skills\ 底下（不是放到桌面或下載夾）；② 資料夾裡要直接看得到 SKILL.md（不要多包一層資料夾）。放好後重開 Claude Code。

      
拆稿只給我摘要，沒有七段完整輸出？
跟它說：「照拆稿格式重來：爆款核心、七宗罪情緒邏輯、八大模組、九大流量法則、主攻口播稿、為什麼更容易爆、純口播稿，七段缺一不可。」

      
純口播稿裡混了標題符號或畫面提示？
跟它說：「純口播稿只准有我會念出口的話，去掉所有 #、HTML 標籤、字卡標記，重出一次。」

      
懶人包生出來就是影片重播？
在它 confirm 章節的時候擋下來：「粉絲要的是影片承諾但沒講完的工具，例如完整步驟／該問的問題／檢查清單，重排章節。」

      
我沒有要拆的逐字稿？
用第 1 堂的逐字稿工具：丟影片連結 → 自動下載 → 生成文字檔。或先拿你自己的舊文案來拆也可以。

      
換了電腦或清了瀏覽器，這頁的設定不見了？
這頁的設定只存在你的瀏覽器裡。不過別擔心——設定早就寫進你電腦裡的 SKILL.md 了，skill 照常運作。要改設定就重填 STEP 01、重跑 STEP 02 的寫入指令。

      
想要 skill 檔案跟完整講義？
點這裡下載學員工具包 zip，裡面有兩個 skill、備援提示詞、Notion 建置指南、安裝講義。
