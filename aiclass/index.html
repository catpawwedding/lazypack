02

建立你的 Notion 文案資料庫（5 分鐘）

🎯 做完這步：每支稿子有一個家，發佈後回填流量，久了長出「你自己的爆款公式」。
打開 notion.so 登入（沒帳號就免費註冊，免費版夠用）。
左側「＋新增頁面」→ 在空白頁輸入 /database → 選「資料庫 - 整頁」。
資料庫命名為 文案資料庫——名稱照這四個字取，之後 AI 才找得到它。
把欄位設成下表（點欄位標題 → 編輯屬性 → 選型態；「＋」可以加新欄位）：
欄位名稱型態選項
標題標題（預設就有）—
類型選取短影音／FB貼文
狀態選取草稿／文案完成／已發佈
平台多選FB／IG／YouTube／TikTok
發佈日日期—
流量數數字—
讚數字—
留言數字—
分享數字—
為什麼要有四個數字欄？ 資料庫的價值不在「存」，在「回填」。發佈一週後把數字填回來，按流量數排序——哪種開頭會爆、哪種主題沒人看，你自己的數據會告訴你，不用猜。

接著把 Notion 接給 Claude（一次設定，終身有效）：

claude.ai 左下角頭像 → 設定 → 連接器（Connectors）。
找到 Notion → 點「連接」→ 用你的 Notion 帳號登入授權。
授權時把「文案資料庫」所在的頁面勾選給 Claude 存取（漏勾它就找不到）。

在終端機執行這一行（官方 Notion MCP），第一次用會跳瀏覽器要你登入授權：

claude mcp add --transport http notion https://mcp.notion.com/mcp

驗收：跟 Claude 說「幫我看一下我的文案資料庫有哪些欄位」，它答得出來就是接通了。

07

      

        
把懶人包交到粉絲手上（三條路）

        
🎯 做完這步：粉絲留言後，你 10 秒內有東西可以私訊給他。

      

    

    

      

        

          
① 直接傳檔案零難度

          
把 HTML 檔案用 LINE 直接傳給粉絲，手機點開就能看。今天就能用，先跑起來最重要。

        

        

          
② Netlify Drop低難度

          
打開 app.netlify.com/drop（免費），把 HTML 檔用滑鼠拖進去，10 秒拿到一條公開網址，私訊貼連結就好。粉絲點連結比開檔案更順。

        

        

          
③ GitHub Pages中難度

          
有 GitHub 帳號的人：開一個 repo → Settings → Pages 開啟。網址永久、所有懶人包累積在同一個倉庫，越做越多變成你的內容資產。課後想升級再走這條。

        

      

      
私訊話術範例：「嗨，謝謝你看完影片！這份『○○懶人包』給你：（連結）。看完有任何問題都可以直接問我 😊」——固定開頭＋連結＋一句歡迎提問，不用寫長。

FAQ

      
卡住了看這裡

    

    

      
Claude 說找不到我的文案資料庫？
九成是授權沒勾到。claude.ai：設定 → 連接器 → Notion → 確認「文案資料庫」所在頁面有勾選給 Claude。另外確認資料庫名稱就叫「文案資料庫」四個字。

      
拆稿只給我摘要，沒有七段完整輸出？
跟它說：「照拆稿格式重來：爆款核心、七宗罪情緒邏輯、八大模組、九大流量法則、主攻口播稿、為什麼更容易爆、純口播稿，七段缺一不可。」

      
純口播稿裡混了標題符號或畫面提示？
跟它說：「純口播稿只准有我會念出口的話，去掉所有 #、HTML 標籤、字卡標記，重出一次。」

      
懶人包生出來就是影片重播？
在它 confirm 章節的時候擋下來：「粉絲要的是影片承諾但沒講完的工具，例如完整步驟／該問的問題／檢查清單，重排章節。」

      
我沒有要拆的逐字稿？
用第 1 堂的逐字稿工具：丟影片連結 → 自動下載 → 生成文字檔。或先拿你自己的舊文案來拆也可以。

      
換了電腦或清了瀏覽器，設定不見了？
這頁的設定只存在你的瀏覽器裡。重填一次 STEP 01 再按儲存即可（建議把填好的內容也備份一份在自己的筆記裡）。

      
想要 skill 檔案跟完整講義？
點這裡下載學員工具包 zip，裡面有兩個 skill、提示詞檔、Notion 建置指南、安裝講義。
